# Гипотезы назначения групп

Гипотезы описывают наблюдаемую структуру, не преступное назначение.
Используются основные роли по документированному порядку; дополнительные
совпавшие признаки роли не считаются отдельными участниками.

Все условия проверяются независимо, поэтому могут быть названы несколько:

| Гипотеза | Проверяемое условие |
|---|---|
| Распределение внутри группы | Есть distributor; не менее 50% внутренней суммы отправлено такими узлами |
| Сбор внутри группы | Есть consolidator; не менее 50% внутренней суммы поступило таким узлам |
| Преобладают получатели без видимого выхода | Не менее 50% участников имеют основную роль terminal |
| Заметная доля транзитных профилей | Не менее 25% участников имеют основную роль transit |
| Смешанная структура | Ни одно условие выше не выполнено |
| Изолят | Один узел без рёбер; данных для назначения недостаточно |

Внутренняя сумма — сумма направленных рёбер внутри группы, каждое ребро
учитывается один раз. Проценты сбора и распределения не складываются:
одна связь может удовлетворять обоим признакам. При нулевой внутренней сумме
эти два условия выключены. Самопереводы учитываются так же, как в основной
сводке; это ограничение агрегатной интерпретации.

Пороговые значения — объяснимые проектные эвристики, не банковский стандарт
и не пороги, обученные по размеченным расследованиям. Для каждой группы
сохраняются основания, ограничения и следующий запрос аналитика.
Текст не утверждает сохранение остатка, происхождение или передачу тех же денег.
