## Передача A и C

- A получает compute_seed_reach(G, nodes) -> gid/seed_reach_count/seed_distance.
- C объединяет признаки с seed-таблицей ДО assign_roles; затем добавляет
  кластеры, приоритет, сводку, top и вызывает write_outputs.
- C сохраняет top.attrs как метаданные политики отбора при необходимости.
- Критично для C: большие gid передавать в JavaScript строками без float.
