- Критично для C: большие gid передавать в JavaScript строками без float.

Замечания владельцу C по текущему viz/app.py (его файлы не менялись):

1. Фильтры применены к top_nodes.csv, поэтому не находят клиентов вне
   общего top-30. Все 30 сейчас из крупнейшей компоненты, лучший клиент
   второй компоненты имеет ранг 128. Для дополнительного просмотра
   фильтровать полную roles-таблицу и затем ранжировать; официальный top
   сохранить отдельно. При non-seed политике нынешний Seed=Да всегда пуст.
2. В таблице списка gid передаётся числом. Все реальные gid >2**53;
   перед отображением преобразовать gid в строки. В графе это уже сделано.
3. Таблица метрик смешивает числа, bool и «—» в одной колонке. Прямое
   преобразование такого столбца в PyArrow падает; поведение Streamlit
   зависит от автоматического исправления. Явно форматировать значения
   строками. Браузерный запуск не выполнен.
4. neighborhood обрезает по gid после обхода и может удалить связующие
   узлы. Пример: 100→90→1 и 100→80→2; hops=2, max_nodes=3 оставляет
   {100,1,2}, без рёбер. Сохранять порядок слоёв BFS и предшественников.
5. «Правило и порог» показывает только role_rule и ссылку на локальную
   документацию. Для объяснения произвольного gid показывать условие
   и фактический рассчитанный порог из модуля/метаданных A.
6. В README pip install стоит до активации созданного venv. Перенести
   активацию перед установкой либо использовать .venv/bin/python.
