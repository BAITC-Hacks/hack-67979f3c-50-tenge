## Оставшееся ограничение

Docker Engine на этой машине не запущен, поэтому сборку образа и команды Compose нельзя подтвердить фактическим запуском. Когда движок будет доступен, выполнить `docker compose run --build --rm pipeline` и `docker compose up --build dashboard`; сверить CSV и открыть порт 8501.

Для сдачи приложить CSV из `out/` отдельно: эта папка намеренно не хранится в git. Репетиция по трём случайным gid и передача организаторам остаются командными действиями.
