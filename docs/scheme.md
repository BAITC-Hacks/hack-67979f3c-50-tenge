# Схема решения

```mermaid
flowchart LR
    A[3 parquet-файла<br/>узлы, рёбра, транзакции] --> B[Проверка данных<br/>полный направленный граф]
    B --> C[Метрики узлов<br/>степени, суммы, PageRank,<br/>betweenness, достижимость seed]
    C --> D[Объяснимые правила ролей<br/>порог + evidence]
    C --> E[Сообщества и<br/>приоритет проверки]
    D --> F[3 проверенных CSV]
    E --> F
    F --> G[Экран аналитика<br/>поиск gid, top-30,<br/>карточка и направленные связи]
```

Роли и приоритет — гипотезы на наблюдаемом графе. Граница глубины 4, неполные входы seed и порог 5 000 KZT выводятся аналитику вместе с результатом. Для презентации приложен [SVG](scheme.svg).
