## Проверка приоритета B

Прочитаны `priority.py`, `seeds.py`, `clusters.py`, `outputs.py` и вызовы
в `run.py`. Формула соответствует §6: 0.35 объём + 0.30 посредничество +
0.20 seed-достижимость + 0.15 степень. Процентили считаются среди положительных
значений, ничьи усредняются; для seed объём и степень берутся по выходу.
Score роли не умножается на приоритет. Порядок объединений C соответствует
контракту: признаки A + seed-метрики B → роли → кластеры → приоритет → CSV.
Расхождений, требующих изменения аналитических модулей A, не обнаружено.

## Замечания владельцам B/C перед сдачей

1. **Совместимость pandas — требуется решение C по зависимостям.** На
   pandas 3.0.6 общий первоначальный прогон дал 94 passed / 1 failed:
   `test_adjacent_large_ids_are_preserved_exactly` падает внутри pandas
   при `.set_index('gid')` для `[2**63-2, 2**63-1]`. Построение RangeIndex
   переполняет верхнюю границу int64. На pandas 2.3.3 весь обновлённый набор
   из 96 тестов проходит. Текущий `pandas>=2.0` допускает проблемную версию.
   Рекомендация C: закрепить проверенный pandas 2.3.3 либо отдельно решить
   совместимость pandas 3 с владельцем B. Не удалять регрессионный тест.
   Рабочие CSV на предоставленных данных созданы и на pandas 3.0.6.
2. C сохраняет `roles.attrs['role_thresholds']` в метаданных запуска до
   следующих merge либо получает их через `compute_role_thresholds`.
   Сейчас `run.py` их не сохраняет; точные пороги есть в `docs/roles.md`,
   округлённые — в evidence соответствующих ролей. Для карточки желательно
   показывать вычисленный порог, а не только имя правила.
3. Необязательные `in_avg_kzt`, `out_avg_kzt` возвращаются A и сохраняются
   в CSV: это средние суммы, NaN при отсутствии переводов. Обязательный
   контракт не расширен; UI отображает отсутствие значения как «не определено».
4. Браузерный сценарий и Docker в этом проходе не проверялись — это
   финальная проверка C. Замечания по интерфейсу из status-b также остаются
   на стороне его владельца. Готовность A не означает проверку всего демо.

Обязательных незавершённых задач A нет. Следующий командный шаг — фиксация
окружения C, проверка UI/Docker и общий проход по трём произвольным gid.
